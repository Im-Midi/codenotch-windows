Guide: 9Router Quota Tracker

Shows every account 9Router manages — Antigravity, Claude, Codex… — with what is left and when it resets, just like its Quota Tracker page.

1 · 9Router on this PC
  1. Install and start it:
npm install -g 9router
9router
  1. Open the dashboard at http://localhost:20128 and sign in once (default password 123456 — change it). That first sign-in creates the token file Codenotch reads.
  2. Connect your accounts in 9Router (Providers). Nothing to type here: tray → Refresh usage now and the 9r cell appears.
2 · 9Router on another computer or server
  1. Server URL: the dashboard's address, e.g. https://9router.example.com. The /v1 ending shown under "API Endpoint" is dropped automatically.
  2. CLI token: run this on the machine running 9Router (inside the container for Docker) and paste the 16-character result.

Linux / macOS / Docker (on macOS use shasum -a 256 instead of sha256sum)

D=${DATA_DIR:-$HOME/.9router}; printf '%s9r-cli-auth%s' "$(tr -d '[:space:]' < "$D/machine-id")" "$(tr -d '[:space:]' < "$D/auth/cli-secret")" | sha256sum | cut -c1-16

Windows (PowerShell) — or install Codenotch there and use Copy this PC's token

$d="$env:APPDATA\9router"; $s=(Get-Content "$d\machine-id" -Raw).Trim()+"9r-cli-auth"+(Get-Content "$d\auth\cli-secret" -Raw).Trim(); -join ([Security.Cryptography.SHA256]::Create().ComputeHash([Text.Encoding]::UTF8.GetBytes($s))|%{$_.ToString('x2')}) | %{$_.Substring(0,16)}
  1. Press Save & test. "Connected to … · N requests today" means it works.
3 · Protected by Cloudflare Access

If the URL opens a "Sign in · Cloudflare Access" page, Codenotch needs a service token:

  1. Zero Trust → Access controls → Service credentials → Service Tokens → Create Service Token. Copy the Client Secret now — Cloudflare shows it once.
  2. Zero Trust → Access controls → Applications → your 9Router application → Policies → Add a policy: action Service Auth, include Service Token → your token. It must be attached to the application; a policy that only exists under "Policies" does nothing, and an Allow policy still asks for a login.
  3. Paste both values under Behind Cloudflare Access? above and press Save & test.
4 · Reading the notch
  • Ring: the one quota closest to running out across all accounts, as the share used — like every other ring.
  • Card (hover the 9r cell): a block per account with the share left, a bar and the reset countdown — as in 9Router. Hover a row for the raw numbers; scroll for more accounts.
  • Accounts refresh every 5 minutes, Claude every 10 — each read makes 9Router ask that vendor, so this stays gentle. Tray → Refresh usage now forces it.
  • Quotas hidden with the eye icon in 9Router's Quota Tracker stay hidden here.
5 · If something goes wrong
"This URL is behind Cloudflare Access…"Add a service token (section 3).
"Cloudflare Access refused the service token"The Service Auth policy is missing, is an Allow policy, or isn't attached to the 9Router application.
"…the saved token is one of its proxy API keys (sk-…)"You pasted an API key from "API Keys". Use the CLI token from section 2.
"Reached 9Router, but it rejected this CLI token"The token belongs to another install, or 9Router's cli-secret changed. Run the command again.
"…answered with a web page" / "redirects to …"The URL isn't 9Router's dashboard address. Check it opens the dashboard in a browser.
An account says "needs re-authorising in 9Router"That provider's sign-in expired inside 9Router — reconnect it there.
6 · Keep it safe
  • The CLI token opens 9Router's admin API (settings, shutdown, updates). Treat it like a password; never share a screenshot of it.
  • To replace it: delete auth/cli-secret in 9Router's data folder, restart 9Router, run the command again.
  • Everything you paste here is kept in Windows Credential Manager, never in a plain file.
